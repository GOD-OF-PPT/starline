# 星际拆解站：再捡一件

驾驶小型打捞船，通过船舱拼装、航路选择和返航决策获取收益，逐步建设自己的太空拆解站。

## 当前阶段

当前仓库包含策划与美术规范，尚未实现游戏或制作正式美术资产。玩法数值、可玩性、性能与实际视觉效果需要在后续原型和试玩中验证。

建议先阅读策划文档，完成 A 阶段核心循环原型，再依据美术规范开展样板制作与正式资产生产。
