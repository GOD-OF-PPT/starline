# 星际拆解站：再捡一件

驾驶小型打捞船，在有限的 4×4 船舱里拼装设备与打捞废宝，公开预测每站战损并权衡冒险深入或满载返航，把带回的收益逐步建设成一座运转中的微缩太空拆解站。

## 运行与测试

```bash
npm install
npm run dev      # 启动本地开发服务器
npm run test     # 运行规则边界单元测试与六类策略确定性平衡模拟
npm run build    # TypeScript 类型检查 + Vite 生产打包
npm run preview  # 本地预览生产构建
```

## 已实现功能范围（首版完整版）

- **4×4 船舱拼装与双模式交互**：支持拖拽摆放（移动端自动抬升预览避免遮挡）与点选放置/旋转/暂存/舍弃及本阶段撤销；L 形与 T 形透明缺口采用精确掩码命中检测；支持桌面快捷键 `R` 旋转、`Esc` 取消选中。
- **8 种设备 + 6 种货物**：激光炮、能量电池（正交相邻最高值生效，单电池可服务多门炮）、护盾板（每战上限 18）、维修无人机（L 形，胜后上限 4），以及数据盒、合金条、冷却罐、旧引擎、折叠天线、古代导航仪（T 形，返航可选择出售或保留收藏）。
- **6 节点双航路与同步交火**：公开展示普通/危险航路的敌舰属性、悬赏、货价范围、优良率及与实战完全一致的战后耐久预测；Phaser 正交侧视战斗场景支持 1×/2× 倍速、快速结算与后台自动暂停。
- **确定性种子随机流与防重复结算**：持久化 PRNG 游标防止刷新重抽，防连续三次同类设备；战斗刷新恢复起始快照重放；基于唯一出航 ID 的幂等结算。
- **基地 2:1 轴测建设与收藏**：破旧/修复双态无跳位切换（拆解工作台、收藏展台、船坞扩建解锁护盾工程艇），古代导航仪修复展示，以及按实装条目计算的图鉴系统。
- **首次 5 分钟引导与可靠性保护**：独立新手教学脚本（不暗改正式随机），自动滚动备份与损坏恢复提示，多标签页单写锁只读保护，低动效/低画质/独立静音设置与 Web Audio 程序化音效与循环背景音。
