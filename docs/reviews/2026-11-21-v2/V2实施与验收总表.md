## 2. 关键设计决策记录（ADR）

- **ADR-01（V1 完整保留与双运行器切换）**：保留全部既有 V1 代码与 `starline_save_v1` 存档零破坏。应用默认进入 V2（`starline_save_v2`），在标题页与设置页提供「切换回 V1 经典模式」入口（及 `?mode=v1` URL 参数）。若首次进入 V2 检测到存在未迁移的 `starline_save_v1`，展示非破坏性迁移向导：支持①直接继续旧版 V1（含进行中航次）；②按 V1 旧规则预览并结算旧航次后一次性迁移至 V2（生成 `migrationId`，永不改写或删除 V1 存档）；③全新开始 V2。
- **ADR-02（兼容既有 4 件藏品与多星域视觉）**：V2 保留全部 4 件手绘藏品（`ancient_navigator` T4、`quantum_core` 2×2、`cryo_amber` 1×3、`obsidian_crown` L3）与星际藏品陈列馆。旧档迁移 100% 完整保留全部 4 件藏品的 `storedCount` 与 `restored` 状态。在 V2 规则内，`ancient_navigator` 沿用策划 1 层基价 45 的常规稀有货地位，其余 3 件藏品在第 4–6 层废船/深层战利品与末层精英中低概率掉落，既不破坏 V2 数值基准，又完全保护了既有藏品资产与玩家收藏进度。6 张手绘星域背景按层深度 1–6 自然呈现，共用统一 V2 规则。
- **ADR-03（BOSS 舰体与多单位战斗融合）**：保留全部既有敌舰与 BOSS 资产。V2 五类遭遇中：`patrol` 使用 `enemy_scout`；`swarm`（4 目标蜂群）使用 4 艘编队化的微型 `enemy_scout`/`enemy_interceptor`；`armored`（装甲护卫）使用 `enemy_frigate`/`enemy_hulk`；`piercer`（穿盾猎手）使用 `enemy_interceptor`；`elite`（末层精英：1 艘 32HP 护卫旗舰 + 2 艘 8HP 护航机）使用 `enemy_boss_dreadnought`（或高深度变体 `enemy_boss_leviathan`）领衔 + 2 艘护航机同屏编队。
- **ADR-04（优良品质启用门槛 T08→T16）**：核心战斗与规则层支持显式 `allowImproved` 开关。T07–T09 综合检查 C 先在纯普通品质下通过多配置×多敌人交叉模拟，证实三种构筑具有清晰克制关系且无单一通解后，再于 T16 正式接入策划规定的层级优良概率（0%/0%/10%/15%/20%/25%，精英 40%）并输出对照报告。
- **ADR-05（远航货船禁用格与 5 列紧凑屏）**：`5×4` 货船在 `360px` 竖屏下按可用宽 `328px` 均分 5 列（每格约 `65.6px`），禁用格 `(4,0)` 与 `(0,3)` 渲染结构封板并禁止落点/旋转/选中；所有功能字号仍保持 `>=12px`。
