## 三、V1 → V2 存档迁移与回滚操作手册

### 1. 存档隔离策略
- **V1 经典版**：读写 `starline_save_v1` / `starline_save_backup_v1`（写锁 `starline_active_tab_lock_v1`）。
- **V2 远航经营**：读写 `starline_save_v2` / `starline_save_backup_v2`（写锁 `starline_active_tab_lock_v2`）。
- V2 任何迁移、结算、重置操作均**绝不改写或删除** `starline_save_v1`。

### 2. 旧版玩家迁移步骤
1. 打开游戏后若检测到本地存在 `starline_save_v1` 且 V2 尚无迁移记录，标题页及基地顶部横幅将提示「导入旧版 V1 存档」。
2. 打开迁移向导可查看精确预览：基地原有信用点、4 件藏品馆已修复/库藏状态，以及若存在进行中 V1 航次时按 V1 旧规则折算的预估信用点。
3. 点击「确认迁移到 V2（保留旧档）」后生成一次性 `migrationId` 完成入账；重复迁移同快照严格幂等不复发钱。

### 3. 随时回滚至 V1 经典模式
- **UI 切换**：在 V2 标题页点击「切回 V1 经典模式」，或进入游戏后点右上「设置 → 切换回 V1 经典模式」。
- **URL 直达**：在本地运行地址后追加 `?mode=v1`（例如 `http://localhost:4173/?mode=v1`）。
- **返回 V2**：V1 界面右下角提供「✦ 返回 V2 远航经营」常驻按钮，点击即可回到 V2 且双方存档互不干扰。

1. **真机触屏测试（iOS Safari + Android Chrome）**：

2. **物理音频与静音测试**：
   - 在桌面与手机外放完整试听：重炮充能+齐射、无人机释放、护盾反击电弧、合同交付与靠泊音效；分别关闭 SFX / BGM 验证静音与刷新持久化。
3. **中低端机性能基准**：
   - 在连发战斗（4 目标蜂群 + 4 架我方无人机 + 近防机炮）与基地 2:1 轴测页录制 30 秒 FPS 与 JS Heap/GPU 显存；对比开启「低画质 + 低动效」前后的帧时间。
4. **3–5 名真人盲测观察清单（T17）**：
   - 不做口头教学，观察被试首次完成 3 层教学时间（目标 3–5 分钟）、是否在 L3 反应堆主动做出「舍弃货物 vs 放弃委托」真实取舍、首趟结束后能否自主理解「入库→研究蓝图→保存预设→换舰/换委托再出航」并记录主观重玩意愿反馈。
