## 五、已实现但待验证事项（明确标注，不伪称已测）

当前云端无头环境无法替代真机硬件与真人主观体验，以下 4 项标记为 **已实现但待验证**：

1. **真实触屏设备手感与防误触**：iOS Safari / Android Chrome 真机上拖拽旋转 `2×3`/`L3`/`T4` 部件的拇指抬升偏移、废船热点点击手感以及横竖屏切换。
2. **真实音频外放听感平衡**：重炮蓄能发射、护盾反击电弧、无人机群升空等程序化 Web Audio 音效与背景音乐在不同音量下的响度与耐听度。
3. **中低端移动 GPU 帧率与显存实测**：2× DPR 与低画质（`1×`）切换在真实中低端手机上的实际 FPS 曲线与 WebGL 纹理显存峰值。
4. **5–12 人首 5 分钟真人盲测（含 Phase D 实验评估）**：借助标题页内置的 **「4 站精华试玩」**（8–12 分钟内可无污染完成试航），邀请真人试玩并采集：
   - 三套流派首战辨识度与重玩意愿；
   - 精英战第 2 回合战术抉择是「显著提升临场爽感」还是「打断自动战斗节奏」，依据盲测反馈决定后续版本默认开/关或移除。
