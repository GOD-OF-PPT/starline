## 3. 美术质量专项检查与提升总结

在完成 F04 资产重建后，我们又对所有高分辨率截图进行了逐帧美术复审，额外发现并解决了 5 项影响画面质感的关键问题：

1. **彻底消除战斗舰船边缘锯齿（核心画质突破）**：
   - 复审发现初版 `768×384` 战舰贴图属于非 2 的幂（NPOT）尺寸，在 WebGL 渲染路径下缩放到手机视口（约 `0.21×`）时跳过 Mipmap 生成，产生明显阶梯锯齿。
   - **提升方案**：将所有 Phaser Canvas 纹理升级为严格 2 的幂（战斗舰船 `1024×512`、基地甲板 `1024×1024`、三座建筑 `512×512`、停泊舰船 `256×256`），并在 `PhaserHost.ts` 开启 `mipmapFilter: 'LINEAR_MIPMAP_LINEAR'` 与 `antialiasGL: true`。复验截图 [`04-combat-upgraded-ships-390x844.png`](./screenshots/04-combat-upgraded-ships-390x844.png) 与 [`12-combat-shield-cruiser-danger-390x844.png`](./screenshots/12-combat-shield-cruiser-danger-390x844.png) 中舰体轮廓、炮管与装甲斜边已完全丝滑无锯齿。
2. **战舰与战场细节强化**：
   - 在 `src/assets/sceneArt.ts` 增加双层白热离子尾焰、通讯天线与信标灯、装甲顶边高光倒角、敌舰后置喷口整流罩与光学镜头反光；
   - 在 `src/scenes/CombatScene.ts` 加入低饱和深空行星弧线、远景漂浮残骸桁架与炮击命中扩散冲击环。
3. **基地微缩场景构图与标注去重**：
   - 在 `src/scenes/BaseScene.ts` 重新计算三座建筑在 2:1 投影下的屋顶最高点，将 `拆解工作台 ✓`、`收藏展台 ✓`、`船坞泊位 ✓` 标签整体上移至建筑轮廓之上，彻底消除标签压住灯棚与展柜玻璃顶框的问题；并加入远景星球轮廓与交叉斜撑轨道桁架。
4. **返航演出遮挡优化**：
   - 将 F11 `.docking-overlay` 由顶部覆盖改为底部贴底渐变条，使靠泊进港舰船与卸货抛物线货箱在基地舞台中央完全无遮挡可见。
5. **UI 工业质感与灰度可读性验收**：
   - 移动端顶部 HUD 改为两行均衡栅格（彻底消除旧版按钮换行后左侧大片空白），为 `.panel` 与 `.cargo-board-outer`/`.cargo-cell` 加入微弱铣削金属内倒角阴影；
   - 依据《美术制作与验收规范》§15 生成纯灰度检查图（[`16-grayscale-arrange-390x844.png`](./screenshots/16-grayscale-arrange-390x844.png)、[`17-grayscale-base-desktop-1366x768.png`](./screenshots/17-grayscale-base-desktop-1366x768.png)），验证物品剪影、品质刻痕、能量连线、网格边框与基地明暗三面层级在无色模式下依然清晰可辨。

## 5. 未完成事项与待验证边界（无验证条件项诚实标注）

以下项目因当前云端无头 Linux 虚拟环境缺乏对应物理硬件或真人样本，**明确标为「待验证」**，不宣称已完成真机/真人验收：

1. **实体移动设备触控手感与浏览器兼容（待验证）**：
   - 真机 iOS Safari / Android Chrome 单手手指拖拽船舱物品时的手指上移偏移、边缘防误触、滚动回弹以及刘海/底栏 `env(safe-area-inset-*)` 安全区表现，需在实体手机上实测确认。
2. **物理音频外放与耳机听感（待验证）**：
   - Web Audio API 程序化合成音效与环境音在真机扬声器/耳机中的响度平衡、不刺耳度，以及 iOS Safari 首次触控手势解锁音频的实机表现，需现场听觉验证。
3. **中低端手机实时帧率与显存实测（待验证）**：
   - 当前环境仅在无头 Chromium (SwiftShader 软件 WebGL) 验证了零报错与 402.75 KB gzip 打包体积；中低端手机 60fps 帧率波动、电池发热与 GPU 纹理显存峰值（`<=200MB`）需在目标机型上使用 DevTools Performance/Memory 实测。
4. **8–12 人目标玩家零讲解盲测（待验证）**：
   - 策划蓝图要求的新手前 5 分钟无外部讲解理解率、规则清晰度与核心乐趣反馈，需由真实玩家试玩采集反馈。
5. **可选后续美术进阶（非阻塞优化项）**：
   - 若未来进入商业化美术打磨，可进一步将程序化 Canvas 资产升级为离屏高精手绘 PNG 贴图集（保持现有 `manifest.ts` 键名与锚点契约不变），并在战斗场景引入舰体受击局部裂痕/烟雾状态表现。
