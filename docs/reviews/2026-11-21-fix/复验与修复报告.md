## 3. v3.0 深空拓荒扩充总结（沿手绘资产体系全面升级）

在 v2.0 完整游戏闭环与手绘资产管线基础上，本次 v3.0 扩充新增 **10 张统一工业科幻手绘 WebP 成品资产**（全库共 **37 张，1,596 KB**），围绕 4 大核心模块实现深度内容扩展：

1. **电影感手绘开场标题界面（Title Screen）**：
   - 新绘 16:9 宽屏主视觉 `public/assets/ui/title_key_art.webp`（`112 KB`）：展示轨道拆解站全貌、发射升空的打捞炮艇、深空巨舰肋骨残骸与星云中潜伏的旗舰剪影，搭配缓慢呼吸漂移动画与左右分层暗角遮罩。
   - 实时读取本地存档遥测：新玩家展示四大特性标签与 `▶ 启动打捞航程`；有进度玩家展示信用点、藏品 `X/4`、图鉴完成度与最深节点，并自动切换为 `▶ 进入拆解站` 或 `▶ 恢复航次（第 N/6 站）`。
   - 完整兼容无障碍与可靠性：标题层对底层 `.app-shell` 施加 `inert`，在标题页打开说明/设置/图鉴弹窗时自动将 `#title-host` 也锁定为 `inert`；同会话进入后通过 `sessionStorage` 记忆避免刷新打断，基地左上角品牌名支持随时一键返回标题页；F03 损坏恢复弹窗自动绕过标题层直达用户。
2. **6 大独立手绘星域 + 可解锁「星渊禁区」前沿航线**：
   - 新增 3 张手绘深空战场背景：`sector_4.webp`（断轨中转枢纽，翡翠青蓝失重环形站与集装箱柱）、`sector_5.webp`（晶化残骸星带，冰晶棱柱与冻结舰骨）、`sector_6.webp`（古代星门深渊，绯红裂隙与巨型石钢环门），与原有 `sector_1..3.webp` 构成标准 6 节点**每站一景、零重复**的星域递进体验。
   - 新增可解锁**「星渊星门禁区 (`abyssal`)」**（修复工作台或抵达第 3 站解锁）：基地出航坞提供双航线切换，星渊航线提供更高敌舰强度（`1.15× HP`、`+1 攻`）与丰厚回报（`+35%` 悬赏、`+20%` 货值、`+15%` 优良率、最高 `68%` BOSS 藏品爆率），并重排深空星域序列（第 1 站直入晶化静默外带）。
3. **双 BOSS 旗舰战 + 精英海盗截击艇**：
   - 新增 3 艘 `512×256` POT 透明手绘敌舰：`enemy_interceptor.webp`（赤翼骷髅海盗突袭艇）、`enemy_boss_dreadnought.webp`（铁壁无畏旗舰：双层垂向锤头舰首 + 上下叠置双联轨炮 + 炽热熔炉核心）、`enemy_boss_leviathan.webp`（黑曜利维坦：黑曜装甲分叉裂口 + 鎏金符文 + 蓄能等离子巨炮）。
   - 节点 6 全面升级为双 BOSS 抉择（普通 `★ 旗舰 BOSS · 铁壁无畏旗舰` vs 危险 `★ 终极 BOSS · 黑曜利维坦`）；`CombatScene.ts` 加入低沉主力舰号角（`bossAlarm`）、巨舰重量感缓慢进场、`1.22×–1.24×` 体型缩放、锤头舰双层轨炮齐射、利维坦巨口蓄能光球与绯红攻城光束、以及击毁时的三层扩散冲击波。
4. **4 件手绘深空藏品 + 星际藏品陈列馆 + 展台实景演进**：
   - 新增 3 件异形透明手绘藏品：`cargo_quantum_core.webp`（`2×2` 量子星核）、`cargo_cryo_amber.webp`（`1×3` 星渊琥珀匣）、`cargo_obsidian_crown.webp`（`L3` 黑曜舰桥冠徽，右上空格 100% 实透），与 `cargo_ancient_navigator.webp`（`T4` 古代导航仪）共同组成 4 件收藏体系。
   - 掉落表按航程深度渐进提升且保持原有 80 种子数值平衡（`tests/simulation.test.ts` 全绿）；结算页与 `applyExpeditionSettlement()` 泛化支持单次同时留存多件藏品；新增互动式 **星际藏品陈列馆 (`openRelicGalleryModal`)** 支持原位逐件修复与和弦音效（`relicRestore`）；`BaseScene.ts` 玻璃展柜随 `0/4..4/4` 动态增亮并环绕对应配色悬浮藏品光球，全收集 `4/4` 点亮金青双环皇冠光晕。

## 5. 未完成事项与待验证边界（无验证条件项诚实标注）

以下项目因当前云端无头 Linux 虚拟环境缺乏对应物理硬件或真人样本，**明确标为「待验证」**，不宣称已完成真机/真人验收：

1. **实体移动设备触控手感与浏览器兼容（待验证）**：
   - 真机 iOS Safari / Android Chrome 单手手指拖拽船舱物品时的手指上移偏移、边缘防误触、标题页全屏适配以及刘海/底栏 `env(safe-area-inset-*)` 安全区表现，需在实体手机上实测确认。
2. **物理音频外放与耳机听感（待验证）**：
   - Web Audio API 合成音效（含新增 BOSS 号角 `bossAlarm`、藏品修复和弦 `relicRestore`、跃迁/爆炸/维修脉冲）与环境音在真机扬声器/耳机中的响度平衡、不刺耳度，以及 iOS Safari 点击标题页「进入」解锁音频实机表现，需现场听觉验证。
3. **中低端手机实时帧率与显存实测（待验证）**：
   - 当前环境仅在无头 Chromium (SwiftShader 软件 WebGL) 验证了零报错、37 张 WebP 资源体积（`1,596 KB`）与打包体积；中低端手机 60fps 帧率波动（尤其是 BOSS 战粒子与三层冲击波）、电池发热与 GPU 纹理显存峰值（`<=200MB`）需在目标机型上使用 DevTools Performance/Memory 实测。
4. **8–12 人目标玩家零讲解盲测（待验证）**：
   - 新手前 5 分钟无外部讲解理解率、星渊禁区解锁激励、双 BOSS 节奏与 4 藏品长线收集反馈，需由真实玩家试玩采集反馈。
